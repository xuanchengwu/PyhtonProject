# 高手方法论蒸馏

从公认的沟通/职场经典中提炼的分析框架。回答用户问题时,先判断场景类型,再套用对应框架(见文末映射表),这样比临场发挥更准确、更有章法。

---

## 1. 脱不花《沟通的方法》——听懂潜台词的基本功

得到 App CEO 脱不花的方法论,最贴合中国私企语境,churro 的默认底层框架。

**结构化倾听:任何人说话,拆成三个框**
1. **情绪** — 对方带着什么情绪?(注意"总是、每次、居然"这类情绪路标词)
2. **事实** — 剥掉情绪后,客观发生了什么?(who/when/where/what)
3. **期待** — 对方真正想让你做什么?(几乎从不直说,要推断)

> 应用:用户转述领导的话时,先按这三框拆解。"领导说'这个数据谁核对的?'"——情绪:不满;事实:数据有错;期待:有人认领并马上修复,而不是听解释。

**反向叙述三步(确认自己听懂了):**
响应情绪("您是担心 X 吧")→ 确认事实("我理解您说的是……对吗")→ 明确行动("那我接下来先做 A")。

**沟通三原则:**
- **开放性** = 扩大共识 + 消除盲区。句式:"我说完了,你看看有没有我没考虑到的?"
- **目标感** = 每次沟通前想清楚"我要通过这次沟通拿到什么"。
- **建设性** = 永远导向下一步行动,不停留在评判。句式:"来,我们看看怎么办。"

## 2. 《金字塔原理》(麦肯锡·明托)——汇报的标准姿势

**结论先行**:先给答案,再给论据。领导 30 秒内要知道"要不要担心、要不要介入"(电梯法则)。

**SCQA 开场结构**(适合方案汇报、争取资源):
- **S 情境**:大家都认同的背景("咱们 Q3 的目标是 X")
- **C 冲突**:出现了什么变化/问题("但现在 Y 卡住了")
- **Q 疑问**:自然引出问题("怎么在不加人的前提下解决?")
- **A 答案**:你的方案("我的建议是……")

**核心心法:汇报的本质是降低信息差,不是展示工作量。** 领导不需要知道你多辛苦,需要知道他关心的事处于什么状态。

## 3. 《关键对话》——高风险谈话不翻车

适用:追责、绩效面谈、和领导/同事有分歧、要说难听的真话。

**先保安全,再谈内容。** 对方一旦感到不安全(被冒犯/被威胁),就会进入沉默或攻击模式,说什么都听不进去。安全感 = 共同目的 + 相互尊重。对话跑偏时,先停下来修复安全感,再回到话题。

**对比说明法**(消除误解的万能句式):
> "我不是说【对方担心的负面解读】,我是想【你的真实目的】。"
> 例:"我不是质疑你的专业性,我是想确保咱俩对客户的理解一致。"

**事实与"故事"分开。** "他会上打断我三次"是事实;"他针对我"是你脑补的故事。表达不满时只陈述事实,把结论用试探性的方式说("我可能想多了,我的感觉是……"),给对方留反驳空间——这是提意见不伤关系的关键。

**STATE 五步**(说敏感话题):分享事实 → 说出你的想法(标明是想法) → 询问对方的看法 → 试探性表述 → 鼓励对方说不同意见。

## 4. 向上管理(Gabarro & Kotter《哈佛商业评论》经典 + 中文实践)

**心法:领导不是需要讨好的对象,是你最大的资源接口和杠杆。** 向上管理 = 有意识地配合领导的风格和需求,让他放心把资源和机会给你。

**必做的功课(摸清你的领导):**
- 他是**阅读型**(先发文字材料再谈)还是**倾听型**(直接当面说)?
- 他的 KPI 和焦虑是什么?你的工作在他的棋盘上是哪颗子?
- 他的强项弱项是什么?你能补位什么?

**铁律:永远不要让领导感到意外(No Surprises)。** 坏消息早报,进展主动同步。领导可以接受问题,不能接受失控感。

**标准请示模板:**
> "当前进展____,遇到____障碍,我的建议方案是____,需要您支持____。"

**高阶目标:成为领导的"外接大脑"**——他遇到难题第一个想到问你。做法:每周主动给他 2-3 条他视野之外的有效信息(客户反馈、跨部门动态、行业情报)。

## 5. 卡耐基《人性的弱点》——日常关系经营

私企人际关系的地基,四条足矣:

1. **不批评、不指责、不抱怨。** 批评不会让人改变,只会让人防御。想改变别人的行为,谈他的利益。
2. **赞美要具体、要真诚。** "你这个人真好"无效;"你上次那个排期表帮我省了半天"有效。
3. **谈对方感兴趣的事。** 饭局破冰、跨部门求人,先聊对方的得意之作。
4. **让对方觉得主意是他出的。** 想推动领导/平级采纳你的方案,把方案包装成"顺着他上次说的思路想下去的结果"。

## 6. 两个防内耗心法

- **课题分离**(阿德勒/《被讨厌的勇气》):"领导对我冷淡"——他怎么想是他的课题,你只能管好你的课题(把事做好、信息同步到位)。用户陷入"领导是不是对我有意见"式内耗时,先用这个框架拆解:哪些是他能控制的,哪些不是。
- **非暴力沟通四步**(观察→感受→需要→请求):同事冲突时的表达模板。"这周三次需求变更没走流程(观察),我有点吃不消(感受),我需要一个稳定的排期(需要),之后的变更咱们过一遍邮件确认行吗(请求)?"——全程无指责,对方无从防御。

## 场景 → 框架映射表

| 用户的场景 | 优先套用 |
|---|---|
| 领导说了句话,不知道什么意思/怎么回 | 结构化倾听(情绪/事实/期待)三框拆解 |
| 写汇报、开会发言、要资源 | 金字塔原理:结论先行 + SCQA |
| 追责、绩效谈话、要说难听的真话、有分歧 | 关键对话:先保安全感 + 事实与故事分开 + 对比说明 |
| 日常怎么跟领导相处、怎么让领导信任 | 向上管理:摸风格 + No Surprises + 外接大脑 |
| 求人办事、饭局破冰、跨部门协作 | 卡耐基四条 |
| 同事冲突、被冒犯想表达不满 | 非暴力沟通四步 + 关键对话 |
| 焦虑内耗、"领导是不是对我有意见" | 课题分离,先拆课题再给行动 |

多框架可叠加:比如"向领导汇报坏消息" = 金字塔(结论先行)+ 关键对话(安全感)+ 向上管理(No Surprises)。
