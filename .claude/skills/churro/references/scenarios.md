# 高频场景手册

每个场景给出:意图分析 → 应对策略 → 示范话术 → 雷区。

---

## 一、领导提问类

### 1.1 "你最近忙不忙?"

**可能意图(按常见度排序):**
1. 要派新活,先探你的容量
2. 觉得你产出不够,敲打你
3. 单纯寒暄/关心(少见,但存在)

**策略:** 永远不要答"不忙"(等于说自己闲),也不要答"特别忙"(显得抗压差或拒人千里)。标准答法是**"忙+具体在忙什么+留口子"**——既展示了工作量,又表明可以接活。

**话术:**
> "最近主要在推 X 项目,这周在赶 XX 节点。您有什么安排吗?我看看怎么排一下。"

**雷区:** 答"还行/一般",信息量为零,领导会觉得你敷衍。

### 1.2 "你觉得 XX(同事)怎么样?"

**可能意图:**
1. 在考察 XX(晋升/调岗/辞退前的侧面了解)
2. 在考察**你**——看你的判断力和口风
3. 已有结论,找认同

**策略:** 夸要具体,批评要克制。只说自己**直接合作中观察到的事实**,不传二手评价。如果领导明显想听坏话,给"中性事实+让领导自己下结论"。

**话术:**
> "我跟他在 X 项目上合作过,他响应挺快的,交付质量也稳。其他方面我接触不多,不好评价。"

**雷区:** 顺着领导贬低同事——这些话大概率会传回去,而且领导会记住你口风不严。

### 1.3 "这个方案你怎么看?"(方案是领导定的/领导支持的)

**可能意图:** 找认同为主,但也在看你有没有独立思考。

**策略:** 先肯定方向(真诚地找出确实好的点),再以"补充/细化"的姿态提出疑虑,把反对意见包装成执行层面的问题。

**话术:**
> "大方向我觉得是对的,尤其是 X 这点解决了咱们一直的痛点。执行上我有个小顾虑:YY 这块可能要提前跟 Z 部门通个气,不然落地时容易卡住。"

**雷区:** 当众直接说方案有问题。有异议私下提,当众只提"执行细节"。

### 1.4 "出了问题,你说说怎么回事?"(追责场合)

**策略:** 三段式——**先认领自己的部分,再讲事实链条,最后给补救方案**。不主动甩锅,但要把时间线和关键节点说清楚(谁在哪个节点做了什么决定),让事实替你说话。重点放在"接下来怎么办",领导最想听的是止损方案。

**话术:**
> "这个事我先说我的责任:X 环节我确认得不够仔细。整个过程是这样的:(时间线,客观陈述)。现在最要紧的是止损,我建议先 A,然后 B,今天下班前我给您一个完整的补救方案。"

**雷区:** 第一反应就解释"不是我的问题"——即使真不是你的问题,也要先陈述事实再让领导自己判断,自辩姿态会让领导烦躁。

## 二、汇报请示类

### 2.1 日常汇报的黄金结构

**结论先行**:一句话结果 → 关键数据/进展 → 问题和需要的支持 → 下一步计划。领导时间宝贵,30 秒内让他知道"要不要担心、要不要介入"。

**微信汇报模板:**
> "X 项目进展同步:本周完成了 A 和 B,整体进度正常(60%)。有一个风险:C 依赖 Z 部门的数据,他们排期比较紧,可能需要您帮忙推一下。下周计划完成 D。"

### 2.2 请示的正确姿势:带方案,不带问题

不要问"这个怎么办",要说"我建议 A,理由是……,您看行吗"。给领导做**选择题**(最好附你的倾向),不要给他做**问答题**。

**话术:**
> "关于 X 有两个方案:方案 A 快但成本高,方案 B 稳但要多一周。我倾向 B,因为这个节点客户更在乎质量。您觉得呢?"

### 2.3 坏消息怎么报

**原则:坏消息要早报、当面报、带方案报。** 拖到瞒不住才说是职场大忌——领导可以接受项目出问题,不能接受被蒙在鼓里。

顺序:口头/电话先说(快、不留难看的痕迹)→ 商量出初步对策 → 再补一条书面的"情况+对策"(留痕的版本要体现"已在处理")。

## 三、饭局酒局类

### 3.1 敬酒的规矩(通用版)

- 顺序:先主宾/最大领导,再按职级依次来;自己是小辈,等领导们互敬完再上。
- 姿势:碰杯时杯沿低于对方;敬酒说词要具体("感谢您上次在 X 事上帮我把关"比"我敬您"强十倍)。
- 不能喝:提前打招呼 + 以茶代酒 + 态度到位。"我酒精过敏,今天以茶代酒,心意是一样的,我先干为敬。"——关键是姿态,不是酒。

### 3.2 领导让你挡酒/代喝

能喝就接(这是信任),不能喝就把话术备好:
> "我替我们领导先敬您一杯——他今天还要开车/等会还有个会,我先干了,您随意。"

### 3.3 饭局上的话题安全区

安全:行业动态、对方的得意项目、美食旅行、夸对方团队。
危险:薪资、公司八卦、评价不在场的人、政治、别人的家事。被问到危险话题,用"这个我还真不了解"+反问对方转移。

## 四、同事关系类

### 4.1 防甩锅:留痕三件套

1. 口头约定的事,事后补一条微信/邮件确认:"刚才说定的:你负责 A,周三给我;我负责 B。有问题随时说。"
2. 关键交付节点,拉上领导抄送。
3. 别人拖延导致你延期,提前(而不是出事后)书面同步风险:"X 还没收到,可能影响周五交付,同步一下。"

**注意:** 留痕的姿态要自然,像"对齐信息",不能像"收集证据",否则关系先崩。

### 4.2 功劳被抢

**当场:** 不撕破脸,但补位发言:"对,这个方案当时我这边做了 X 和 Y 的部分,有个细节可以补充一下……"——用细节自然证明参与度,细节是抢功者说不出来的。

**长期:** 养成过程中定期同步进展的习惯(见 2.1),功劳的归属在日常汇报里就已经确定了,不会等到最后一刻才争。

### 4.3 同事请你帮忙,不想帮/帮不了

婉拒公式:**态度上接住 + 客观困难 + 给个替代出口**。
> "这事我还真想帮你,不过我这周被 X 项目的节点卡死了,实在腾不出手。你要不问问 XX?他之前做过类似的。"

## 五、利益谈判类

### 5.1 谈加薪

- **时机:** 刚做出可见成绩之后、公司调薪周期之前;别在领导焦头烂额时谈。
- **姿势:** 谈"贡献与匹配",不谈"生活困难"或"别人拿多少"。
- **话术:**
> "想跟您聊聊我的发展。这一年我负责了 X 和 Y(具体成果、数据)。我希望薪资能和目前承担的职责匹配一些,想听听您的看法,也想知道接下来我还需要在哪些方面再提升。"
- 结尾把姿态放在"发展"上,给领导台阶——即使这次不成,也埋下了下次的引子。

### 5.2 提离职

- 顺序:**先口头跟直属领导单独说,再走流程。** 让领导从 HR 或别处先知道,是撕破脸的做法。
- 理由:说"个人发展",不吐槽公司和任何人——离职谈话里的每一句抱怨都毫无收益。
- **话术:**
> "跟您单独说一下,我经过挺长时间考虑,决定换个环境试试,主要是个人发展方向的考虑。非常感谢您这几年带我(具体说一两件事)。交接我会安排好,保证不影响团队。"

### 5.3 被谈话挽留/画饼

不当场答应,也不当场拒绝:
> "谢谢您的认可,这些我都会认真考虑。您容我想两天,想清楚了给您答复。"
——回去把口头承诺的条件(涨薪数字、晋升时间)想办法落成书面,落不成书面的饼,含水量自行判断。
